# Campus Compass 🧭

Campus Compass is a responsive campus discovery web application
designed to help college students discover, explore, and shortlist
nearby places.

The initial use case focuses on helping students find libraries
near Christ University.

## Problem Statement

Students may find nearby places using mapping applications, but
evaluating and shortlisting suitable places for a specific purpose
can require additional effort.

Campus Compass explores a more focused discovery experience with
category filtering, place information, map markers, and saved places.

## Features

- Search for places by location
- Explore different place categories
- View locations on an interactive map
- Calculate approximate straight-line distances
- Save favourite places
- Store saved places using localStorage
- Display loading, error, and empty states
- Responsive interface for desktop and mobile

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Vite
- Leaflet
- OpenStreetMap
- Nominatim
- Overpass API
